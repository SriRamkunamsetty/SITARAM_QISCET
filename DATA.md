# Data provenance

Pratibimb never commits third-party clinical data. Everything below is either generated by this
repository or downloaded by each user under the source's own licence.

| Dataset | Used for | Licence / access | In repo? |
|---|---|---|---|
| **Synthetic Indian cohort** (`pratibimb.cohort.virtual`) | Development, strip-budget experiment, tests, demo | Generated here, Apache-2.0 | Generated at run time |
| **ShanghaiT2DM** (Zhao et al., *Sci Data* 2023; Figshare 20444397) | Real-data validation (CGM + meds + diet + labs, 100 T2D) — *next milestone* | CC BY 4.0 | No — `scripts/download_data.py shanghai` |
| **CGMacros** (PhysioNet 1.0.0) | Real two-stream fusion (EHR labs + Fitbit + CGM) — *planned* | CC BY-NC-SA 4.0 | No — download from PhysioNet |
| **AI-READI** v3 | Large-scale validation if access is approved — *planned* | Controlled (DAC review) | Never |

## How the synthetic cohort is calibrated

| Element | Source | Status |
|---|---|---|
| Endotype shares (SIDD 26.2%, IROD 25.9%, CIRDD 12.1%, MARD 35.8%) and centroids (age at dx, BMI, waist, HbA1c, HOMA-IR, HOMA-B) | INSPIRED, Anjana et al., *BMJ Open DRC* 2020 (PMC7437708) | Published values |
| S_I ∝ 1/HOMA-IR, beta-cell and SU response ∝ HOMA-B | Modelling assumption | To be refit on real data |
| Untreated basal glucose per endotype | Modelling assumption; on-treatment HbA1c is an *output* (ADAG formula) | Cohort mean HbA1c ≈ 7.7% on SU |
| Glycaemic index of Indian breakfasts (idli 85, dosa 76, upma 71) | Tan et al., *Br J Nutr* 2018 | Used in default meal template |
| Carbs-last food order slows gastric emptying | Meta-analysis, *Acta Diabetol* 2025 (17 RCTs) | Direction implemented; magnitude to be calibrated |
| Wearable → insulin-resistance direction (higher RHR, fewer steps → higher HOMA-IR) | WEAR-ME, *Nature* 2026 | Direction only; magnitudes provisional |
| Hypoglycaemia definition (<70 mg/dL for ≥15 min; level 2 <54) | International CGM consensus (Battelino et al., *Diabetes Care* 2019) | Implemented |
| Meter error (ISO 15197 class) and CGM error (~9% MARD, AR(1)) | Device standards | Implemented |

## Honest limitations of the synthetic data

- The virtual cohort under-represents **nocturnal** hypoglycaemia relative to published CGM
  studies of sulfonylurea users (most simulated lows occur late morning at the glimepiride
  peak). Night-window results are therefore reported separately and should be read as a lower
  bound on the planner's value for overnight risk.
- The twin and the truth simulator share model structure. Evaluation uses deliberate mismatch
  (per-patient perturbation of fixed constants, day-to-day parameter drift, carb-counting error,
  unlogged snacks, missed doses, device noise), but **real-data validation is required** before
  any performance claim transfers to patients.
